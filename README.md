# NotebookLM Clone

An open-source implementation of Google's NotebookLM that grounds AI responses in your documents with accurate citations. Built with modern AI technologies including RAG (Retrieval-Augmented Generation), vector databases, and conversational memory.

## Setup

1. Install `uv` and dependencies:
   ```bash
   uv sync
   ```

2. Copy `.env.example` to `.env` and fill in your API keys.

3. Run the app:
   ```bash
   uv run app.py
   ```
